      Učitaj JSON s testnim slučajevima ili automatski generiraj 300 pseudo-OHBP nalaza. Regresijski test uspoređuje parser s očekivanim vrijednostima i javlja točna polja koja su pala.
      Nema učitanih regresijskih testova.
      Ctrl + Alt + P sprema trenutnog pacijenta kao test parsera privremeno u ovoj sesiji i preuzima lokalni JSON. Online spremanje parser testova je isključeno. Podržani format: niz objekata { id, scenario, raw, expected } ili omotnica { cases: [...] }. U expected možeš koristiti npr. fullName, birthYear, admissionDate, diagnosisContains, therapyContains, ohbpTherapyContains, labRawContains, labRawNotContains.
